How do I get the email into Outlook?

Click Open new Outlook email first to start a fresh draft. Then click the three step buttons in order: (1) Copy email body — paste into the message with Ctrl+V (full table appears formatted). (2) Copy recipients — paste into the To, Cc, or Bcc field. (3) Download Excel — drag the file onto your Outlook window to attach. Three buttons. Three pastes. Done.

Does pasting really preserve the formatting?

Yes, in modern Chrome, Edge, and Safari. The "Copy email body" button copies the email as both rich HTML and plain text on your clipboard. When pasted into Outlook (a rich-text editor), it picks up the HTML version and renders the formatted table with colors and structure intact. If you're on an older browser and it doesn't work, click "Preview email", then select-all and copy from there as a fallback.

What's in the bulk email?

A grouped table organized by person — each person appears once with their full name, email, and manager, followed by all their pending trainings underneath (training name, required date, days remaining, type). No more reading the same name 17 times. The Excel attachment contains the full data with several views (summary, by-manager, by-source, missing-email).

Why are some emails marked "missing email"?

The agent looked up each person from your PDFs in the rosters you provided. If they're not there, the row is preserved but flagged. They won't be included in the bulk recipient list. To resolve, add another roster spreadsheet that contains those people.

Is my data safe?

Yes. This is a single HTML file that runs entirely in your browser. No data is uploaded anywhere. The only network requests are to load the open-source PDF and Excel libraries from a public CDN at page load. You can verify this in browser developer tools.
